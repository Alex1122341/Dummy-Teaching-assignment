Accounts

Spark Basic Mode: create the login first in Firebase Console → Authentication → Users. Then paste that user's UID here to link the login to a UCVM access role. This page does not create Authentication users.

Access roles: Owner is the highest role and controls User Management. Administrator manages the faculty/timetable workflow. Other Office currently has the same operational permissions as Administrator, but is kept as a separate role so it can be restricted later. HICC, VISC and Faculty are faculty-facing roles.

For a forgotten password, use Send password reset. Firebase sends the reset email directly; no Cloud Function is used.

HICC Groups

Each group belongs to an HICC. Owner assigns the HICC owner and course scope. HICCs can add or remove members in their own groups. Timetable changes requested by HICCs/faculty continue through the approval workflow before becoming live.
